## Step 3: Create Event Types

- Name: Portrait Session
- Description:

  What's included:
  • 60 minutes of shooting
  • 1 location (studio or outdoor)

## Step 5: Connect Google Calendar

1. Go to "Integrations" → "Google Calendar"
2. Click "Connect"
3. Authorize Calendly
4. Verify connection shows "Connected"

**Important:** In Calendly scheduling pages, enable "Checking for conflicts"

## Common Issues

| Issue | Solution |
|-------|----------|
| Calendar not syncing | Reconnect calendar in Integrations |
| Double bookings | Check "Checking for conflicts" enabled |
| Wrong timezone | Verify in Account Settings → Profile |
| Questions not showing | Save event type after adding questions |
