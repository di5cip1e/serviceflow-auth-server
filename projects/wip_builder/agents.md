# Project Guidance

## Engagement Suggestions

When generating suggestions or next-step prompts for this project:

- **Never suggest replacing, regenerating, or creating new visual assets.** The existing assets are curated to fit the project's theme and should not be changed.
- **Never suggest adding new images, sprites, textures, or asset generation.** Asset generation does not reliably match the existing art style.
- Focus suggestions on **gameplay mechanics**, **story and narrative**, **UI/UX improvements**, **game balance**, **new features**, and **polish** (animations, transitions, sound effects via code).
- Keep suggestions specific to what this project already does — reference actual game elements, not generic categories.
