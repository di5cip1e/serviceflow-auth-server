## 3. Priority Order

### Tier 1: Core Gameplay (Generate First)
1. **Remaining Terrain Tiles** - Game can't function without all terrain types
2. **Government Units Tier 1-2** - Basic units for each government type
3. **Core UI Elements** - Health bar, resource panel, selection ring

### Tier 2: Essential Features
4. **Remaining Government Units** - Tier 3-4 elite units
5. **Additional Buildings** - Academy, Library, Wall
6. **Combat Effects** - Attack, heal, shield effects

### Tier 3: Polish & Depth
7. **Icons** - Gameplay action icons
8. **Backgrounds** - Menu, battle, city views
9. **Remaining UI** - Tooltips, portraits, minimap

### Tier 4: Nice to Have
10. **Advanced Effects** - Buffs, debuffs, level up
11. **Improvements** - Roads, farms, watchtowers
12. **Additional Landmarks** - Flavor assets

## 4. Artist Prompts

### Terrain Prompt Template
```
Isometric tile art, [terrain type] terrain, dark fantasy aesthetic, subtle purple/blue ambient lighting, mystical atmosphere, sharp edges, game-ready sprite, centered composition, transparent background, PNG format
```

### Unit Prompt Template
```
[Unit type] character sprite, isometric view, dark fantasy art style, detailed [armor/clothing description], [pose description], subtle glow effects, game-ready sprite sheet potential, purple-blue ambient lighting, transparent background, PNG format
```

### Building Prompt Template
```
Isometric building/structure, [building type], dark fantasy architectural style, mystical atmospheric lighting, [material description], subtle purple ambient glow, game-ready sprite, centered, transparent background, PNG format
```

### UI Prompt Template
```
Dark fantasy UI element, [element type], ornate border with [style], subtle gradient, purple-gold color scheme, game interface ready, transparent background, PNG format
```

### Effect Prompt Template
```
Particle effect sprite, [effect type], glowing magical aesthetic, [color scheme], game-ready transparent PNG, loop-capable edge, centered composition
```
