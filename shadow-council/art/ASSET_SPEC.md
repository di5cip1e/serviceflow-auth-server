# Shadow Council - Asset Specification

## Project Overview
Dark fantasy strategy game with runic/gothic aesthetic. Visual style: ancient, mysterious, powerful — gold accents on deep dark backgrounds.

## Existing Assets
- `counsel_ui_overlay.png.webp` - UI overlay graphics
- `strategy_game_spritesheet.png.webp` - Game sprite sheet
- `ruler_portraits.png.webp` - Ruler portrait sprites
- `trait_icons.png.webp` - Trait icon sprites

---

## Required Visual Assets

### 1. Rune Symbols (SVG priority)
- **Elder Futhark Runes** - 24 symbols for magic/abilities
- **Custom Guild Runes** - Shadow Council branding symbols
- **Elemental Runes** - Fire, Water, Earth, Air, Void
- **Power Runes** - Strength, Wisdom, Courage, Deception

### 2. UI Elements
- **Panel Borders** - Ornate gold-edged frames for windows
- **Button Templates** - Runed button backgrounds
- **Divider Lines** - Decorative separators with rune motifs
- **Corner Ornaments** - Gothic corner decorations
- **Scroll Headers** - Parchment-style headers

### 3. Background Elements
- **Tile Textures** - Dark stone, obsidian, aged wood
- **Atmospheric Overlays** - Fog, dark energy effects
- **Map Tile Borders** - Province/territory markers

### 4. 3D Assets (lower priority)
- **Rune Stone Models** - Glowing runic pillars
- **Throne Room Elements** - Council table, seats
- **Battle Arena Props** - Obstacles, altars
