**Steps:** Log in → Go to dashboard → spinner spins forever  
**Expected:** Dashboard loads with data  
**Actual:** Spinner spins forever

**Root cause:** `initApp()` in dashboard.html had no top-level try/catch. If any API call failed (network error, 502, timeout), the page stayed in its default "Loading..." state.

**Fix applied:** Wrapped `initApp()` call in try/catch. On error, the dashboard is shown anyway with a toast notification. This ensures the user always sees the dashboard even if some data fails to load.
