# 2026-03-04 - Session Memory

## Project: Station Command

### What We Built
- A 16-bit style Next.js RPG mission control game where you watch agents battle tasks
- 10 sub-agents with SOUL.md files (coordinator, blueprint_architect, engine_mechanic, frontend_weaver, lore_master, qa_interrogator, devops_enforcer, game_systems_designer, researcher, visual_artist)
- Full backend with 25+ API routes
- Frontend with battle system, dialogue, game loop
- Agent battle system (FF-style RPG battles)
- Pixel sprites and battle music

### Key Technical Decisions
- Backend: Next.js API + Prisma + PostgreSQL
- Frontend: Next.js + React + Zustand
- Auth: NextAuth.js
- Browser automation: Playwright (installed and working)

### Agent System Learnings
- Agents need to be registered via `openclaw agents add` before spawning
- Use `label` not `agentId` when spawning
- Default timeout is ~1 min - need longer timeouts (5+ min) for substantial tasks
- Agents can run in parallel (up to 5 active)

### File Structure Created
- /backend/ - Next.js API (25+ routes)
- /frontend/ - Next.js app (battle, game pages)
- /lore/ - Narrative content + dialogue
- /qa/ - Tests, security audit
- /research/ - Tech stack, battle music, monetization
- /assets/sprites/ - 19 pixel art placeholders
- /infrastructure/ - Docker, deployment docs
- /tools/browser/ - Playwright automation tool
- /EXTERNAL_ACCOUNTS.md - Credential storage

### Deployment Status
- Backend and frontend built successfully
- PostgreSQL database ready
- Environment configured
- Ready for deployment to Vercel/Railway

### Issues Fixed
- Session type errors (used `(session as any)` workarounds)
- Styled-jsx build errors (simplified components)
- Agent timeout issues (increased timeoutSeconds)

### Commands Learned
- `openclaw agents add <name>` - Register new agent
- `sessions_spawn(label="...", runtime="subagent", task="...")` - Spawn agent
- `npx playwright install-deps chromium` - Install browser dependencies
