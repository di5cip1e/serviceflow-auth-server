# Daily Lessons — May 14, 2026

## Top 20 Lessons from May 13-14

### Subagent Execution Patterns
1. **Frontend tasks work well in subagents** — No port conflicts, no PM2 restarts needed. Login/register/settings pages all completed successfully in subagent sessions.
2. **Backend tasks with PM2 restarts time out** — Subagents that need `pm2 restart` hit the 5-min limit fighting with the running process. Handle backend changes directly in main session.
3. **Strategy: split by concern** — Spawn subagents for frontend/file creation, handle backend/server-restart tasks directly. This hybrid approach maximizes parallel work without port conflicts.
4. **Always include TASKS.md in subagent prompts** — Subagents that read TASKS.md first produce more consistent results and can update the tracker on completion.

### Auth System Architecture
5. **Session-based auth > JWT for server-rendered apps** — Simpler, no token refresh logic, works naturally with Express + SQLite. JWT is better for APIs/spas; sessions work better for traditional web apps.
6. **bcrypt cost 10 is the sweet spot** — Fast enough (~100ms/hash), secure enough for production. Don't go higher without benchmarking.
7. **connect-sqlite3 for session store** — Zero config, no external Redis needed, persists across restarts. For single-server deployments, this is ideal.
8. **Rate limiting should be per-IP, not global** — express-rate-limit defaults to per-IP, but when testing from localhost all requests share the same key. For production, consider `keyGenerator: (req) => req.ip` explicitly.
9. **Order of middleware matters** — Auth routes (`/api/auth/*`) must be mounted BEFORE `requireAuth` middleware. Session middleware must be BEFORE both. Static files must be served before route-specific handlers.
10. **Protected pages need explicit routes** — `express.static` only serves css/js/assets subdirectories. HTML files like login.html and register.html need explicit `app.get('/login', ...)` routes to be served correctly.

### PM2 & Process Management
11. **PM2 list can be empty even when process is running** — A process might be running outside PM2 supervision. Always check `ps aux | grep node` AND `pm2 list`.
12. **PM2 restart count reveals hidden crashes** — maikr-backend showed 16 restarts before we fixed the syntax error. High restart count = investigate immediately.
13. **Deleting and re-creating PM2 process clears restart count** — `pm2 delete` + `pm2 start` gives a fresh slate. Useful after fixing the root cause of crashes.

### SQL & Database
14. **SQLite doesn't support IF NOT EXISTS for ADD COLUMN** — Use `PRAGMA table_info()` + conditional ALTER TABLE for idempotent column additions. Created `addColumnIfMissing()` helper.
15. **Mixed quotes in SQL strings break SQLite** — Double quotes (`"`) are for identifiers, single quotes (`'`) for string literals. Escaping: `'that''s wrong'` (doubled single quote).
16. **LOWER() for case-insensitive matching** — Instead of listing all case variants in IN clause, use `LOWER(c.content) IN ('no','wrong','nope')`. Cleaner and catches edge cases.

### Model & Configuration
17. **Models registry controls override permissions** — `agents.defaults.models` acts as an allowlist. Models not in this registry can't be used via `session_status` override. Add new models here first.
18. **Model fallback chain matters** — Primary model (`deepseek/deepseek-v4-pro`) → fallback (`openrouter/deepseek/deepseek-v4-pro`). If primary isn't found, OpenRouter alias kicks in.

### Task Decomposition
19. **TASKS.md is a force multiplier across sessions** — Writing a detailed task breakdown BEFORE starting work lets subagents execute independently with clear success criteria and dependencies.
20. **Design doc + task breakdown = repeatable execution** — AUTH-DESIGN.md (architecture) + TASKS.md (execution steps) meant each subagent had full context without reading prior session history.
