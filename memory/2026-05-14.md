### Architecture decisions:
- Session-based auth (not JWT) — simpler, server-side sessions
- bcrypt cost 10 for password hashing
- SQLite session store via connect-sqlite3
- Rate limiting: express-rate-limit, 5 attempts per 15 min
- User nav links to /api/auth/logout (POST form)
- requireAuth redirects to /login (pages) or 401 JSON (API)
