### Key Learnings (May 19-20)

1. **Stripe.js must be explicitly loaded** — `Stripe()` is not a global. Always include `<script src="https://js.stripe.com/v3/">` before using Stripe.js. Silent failure = button does nothing, no console error in production.

2. **Temporal dead zone with `const`** — In JavaScript, `const` and `let` are hoisted but not initialized. Referencing them in the same scope before the declaration throws `ReferenceError: Cannot access 'X' before initialization`. This applies even within object literals passed to async functions.

3. **OpenClaw v2026.5.12 broke isolated cron sessions** — The update changed internal module paths, causing `ERR_MODULE_NOT_FOUND` for all `sessionTarget: "isolated"` agentTurn jobs. Fix: use `sessionTarget: "main"` with `systemEvent` payloads for simple script execution tasks.

4. **DB schema drift accumulates** — Services written at different times reference columns that don't exist yet. Always verify `PRAGMA table_info(table)` when a service fails with `SQLITE_ERROR: no such column`. The webhook_events, customers, and credit_purchases tables all had missing columns from when they were originally created.
