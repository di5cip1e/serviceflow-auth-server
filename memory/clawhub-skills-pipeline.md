# ClawHub Skills Pipeline

## Skills to Build for Publishing

### Skill 1: N8N Workflow Builder

**What it does:** User describes an automation in plain English → skill outputs a ready-to-use N8N workflow JSON

**Trigger phrases:**
- "Build me a lead capture workflow"
- "Create an invoice follow-up sequence"
- "Set up a social media auto-poster"

**Key features:**
- Natural language to N8N webhook structure
- Pre-built templates for common business automations
- Output as downloadable JSON or direct N8N import link
- Error handling for malformed requests

**Credibility angle:** Shows technical depth (N8N is developer-heavy), positions you as automation expert

**Ethics note:** Include clear documentation that user is responsible for securing their N8N instance and API keys

### Skill 2: Client Outreach Automator

**What it does:** Generates personalized cold outreach sequences (email + LinkedIn + follow-up) based on prospect info

**Trigger phrases:**
- "Write outreach for a real estate agent"
- "Create a follow-up sequence for freelance photographers"
- "Generate cold email for a plumbing company"

**Key features:**
- Pain point analysis based on business type
- 3-touch sequence (initial + follow-up + final)
- Personalization tokens for name/company
- Channel-specific templates (email vs LinkedIn vs cold call)

**Credibility angle:** Demonstrates business development expertise, practical sales knowledge

**Ethics note:** Include disclaimer that outreach must comply with CAN-SPAM, GDPR, and platform terms of service

---

### Skill 3: Meeting Intelligence Suite

**What it does:** Transcribes, summarizes, and extracts action items from meeting notes or recordings

**Trigger phrases:**
- "Summarize this meeting transcript"
- "Extract action items from my notes"
- "Create follow-up tasks from our call"

**Key features:**
- Bullet-point summarization
- Action item extraction with assignees
- Follow-up email drafting
- Priority tagging

**Credibility angle:** Shows productivity focus, appeals to busy professionals

**Ethics note:** Clear consent notice for recording/meeting transcription compliance

---

### Skill 4: Content Repurposer

**What it does:** Turns long-form content (blog post, podcast transcript, video) into platform-specific social posts

**Trigger phrases:**
- "Turn this blog post into LinkedIn posts"
- "Create Twitter threads from this article"
- "Extract quotes for Instagram from this transcript"

**Key features:**
- Multiple output formats (LinkedIn, Twitter, Instagram, Facebook)
- Character limit compliance
- Hashtag suggestions
- Thread threading for long content

**Credibility angle:** Content marketing expertise, demonstrates understanding of platform algorithms

**Ethics note:** Attribute original content, no plagiarism (generate original summaries only)

---

### Skill 5: Business Document Generator

**What it does:** Generates professional business documents (proposals, quotes, contracts, invoices) from templates

**Trigger phrases:**
- "Create a proposal for web design services"
- "Generate an invoice for consulting"
- "Write a contract for freelance work"

**Key features:**
- Template library (10+ document types)
- Customizable variables (client name, services, pricing)
- Industry-specific defaults
- Export to PDF/DOCX

**Credibility angle:** Professional services credibility, shows understanding of business operations

**Ethics note:** Clear disclaimer that documents are templates only and should be reviewed by legal professional
