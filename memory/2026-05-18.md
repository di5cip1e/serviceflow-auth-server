### Key Learnings from May 17-18

1. **CSS External Dependency Risk** — Landing page used `var(--amber)` etc. from external `dark-premium.css`. When that file didn't load (path issue), ALL inline styles broke and page looked "destroyed". Fix: make critical pages self-contained with inline styles and hardcoded color values. Never depend on external CSS for core layout/colors.

2. **Hostinger DNS Issue** — maikr.pro showed "parked domain" page because DNS A record pointed to Hostinger's parking IP (2.57.91.91) instead of the actual server (187.77.31.252). The backend was always healthy — traffic just wasn't reaching it. Fix: update A record to point to correct server IP, TTL 3600.

3. **Subagent File Operations** — owl-alpha model consistently fails on file read/write tasks. Use subagents only for research/analysis, not bulk file editing.

4. **Logo Color Consistency** — M.ai.K.R logo: "M" white, ".ai" amber, ".K.R" white. Applied to both nav and footer.
