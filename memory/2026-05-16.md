## 01:21 UTC — Mailgun Investigation

**Problem:** Mailgun returns 403 `"Domain aginstitute.tech is not allowed to send: exposed account credentials"`

**Root Cause:** The Mailgun API key has been flagged as "exposed" by Mailgun's security system. This happens when an API key is detected in a public repo, pastebin, or other exposed location.

**What's configured:**
- MAILGUN_API_KEY: f3329607... (in secrets.json)
- MAILGUN_DOMAIN: aginstitute.tech
- MAILGUN_FROM: derekbrooks@aginstitute.tech

**Domain DNS status (all sending records valid):**
- SPF: `v=spf1 include:_spf.mail.hostinger.com include:mailgun.org ~all` ✅
- DKIM: valid ✅
- CNAME: valid ✅
- MX: points to Hostinger (not Mailgun) — this is fine for sending, only affects receiving

**Fix needed:** Regenerate the Mailgun API key:
1. Log in to https://app.mailgun.com
2. Go to Settings → API Keys
3. Generate a new "Private API Key"
4. Update `~/.openclaw/secrets.json` with the new key
5. Restart backend: `pm2 restart maikr-backend`

**Not in git history** — the key was never committed to any repo in the workspace.
