### Key Learnings from May 18-19

1. **Server-Side Auth Redirect** — Protected HTML pages were served via `express.static` BEFORE session middleware, allowing unauthenticated access. Fixed by: (a) moving session middleware before static serving, (b) adding a middleware that intercepts requests to protected HTML filenames and runs `requireAuth`, (c) moving `express.static` for frontend to after all route definitions. All 9 protected pages now properly 302 redirect to `/login`.

2. **Build Flow Button Bug (Identified, Not Yet Fixed)** — The "Continue →" button on build steps doesn't advance to next step on click. The click handler appears to `preventDefault()` without properly handling form submission. Direct `form.dispatchEvent(new Event('submit'))` works. This is a critical conversion funnel blocker.

3. **SEO Gaps** — No Open Graph tags, no Twitter Card tags, no JSON-LD structured data, no canonical URLs, no robots meta. H1 heading has missing spaces ("Your AI teamnever sleeps").

4. **Accessibility Gaps** — No `<main>` landmark, no `<header>` landmark, no skip-to-content link. Good color contrast and ARIA labels otherwise.

5. **Performance is Excellent** — 30-40ms server response, 3KB page weight, zero console errors, zero 404s, zero broken images.
